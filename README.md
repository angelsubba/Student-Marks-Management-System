Student Marks Management System

Project Overview

The Student Marks Management System is a web-based application developed using Python and Flask. It helps manage student records, marks, grades and academic performance.

Technologies Used

- Python
- Flask
- HTML
- CSS
- JSON

Features

1. Add new student records.
2. View all student records.
3. Edit student details and marks.
4. Delete student records.
5. Search students using roll numbers.
6. Calculate total marks and percentages.
7. Automatically calculate grades.
8. Generate class performance reports.
9. Display class average and topper information.

Subjects

The system manages marks for five subjects:

- Python
- Mathematics
- Physics
- English
- Computer

Grading System

- 75% and above – Distinction
- 60% to 74% – First Class
- 50% to 59% – Second Class
- 35% to 49% – Pass
- Below 35% – Fail

How to Run the Project

1. Install Python on your computer.

2. Install Flask:
   
   "pip install flask"

3. Open the project folder in VS Code.

4. Open the terminal.

5. Run the application:
   
   "python app.py"

6. Open Google Chrome and visit:
   
   "http://127.0.0.1:5000"

7. Open the deployed website using the Live Website link provided below.

Conclusion

This project provides a simple and user-friendly way to manage student marks and academic records. It reduces manual work and makes student performance analysis easier.
